# Hardware

## PCB

This directory contains the hardware design files for the custom mmWave radar shield used in this project.

The following PCB project is included:

```text
mmWave-shield-pcb/
```

The PCB was designed in KiCad and contains the schematic, PCB layout, local project libraries, and generated fabrication outputs required to manufacture and assemble the board.

Inside the project folder, you can find the KiCad design files as well as generated documentation and fabrication files such as schematics, bill of materials, Gerber files, and 3D model exports.

## Casing

In the folder Casing you can find .stl files for a 3d printed casing model that can be used with the BioGap + mmWave Shield.
