# Casing

This folder contains the 3D model files for the casing used with the mmWave radar shield.

The casing model that was actually used for the validation measurements is located directly in this folder. This includes the exported STEP file and the Solid Edge source file, if further modifications are required.

Images of the relevant casing dimensions and measurements are also included for reference in the `images/` folder.

## Notes

The `old_step_files/` folder contains earlier casing examples. These were not used for the final validation measurements. Compared to the final casing, the older versions have a smaller inner width and the velcro-band extensions are positioned higher up.
